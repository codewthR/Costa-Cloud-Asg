# 🦠 COVID-19 Risk Prediction GUI App

## 🖼️ [Project Sample Pictures](#project-sample-pictures)

## Main Objective
This app is a Tkinter-based GUI :
- Collects user data through a structured input form.
- Shows a fake prediction when the user clicks the Predict button.
